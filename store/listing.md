# Картка для Chrome Web Store

## Назва

Типу лічильник

## Короткий опис (до 132 символів)

Рахує, скільки разів у YouTube-відео прозвучало слово «типу», і показує число поруч із лайком і дизлайком.

## Детальний опис

Слово-паразит «типу» має свій лічильник. Поруч із лайком і дизлайком під відео з'являється ще одна кнопка: скільки разів ведучі сказали «типу» за весь випуск.

Ідея народилась із коментаря під подкастом «Радіо Кнопка». Глядач запропонував: якби він був дизайнером YouTube, то додав би лічильник слова «типу» поруч із лайками. Ми вирішили, що це чудова ідея, і зробили її розширенням.

Як це працює

• Відкрийте будь-яке відео з українськими субтитрами, зокрема автоматичними.
• Розширення читає субтитри, які YouTube уже завантажив для цього відео, і рахує слово «типу» та його варіації: тіпа, типа, типе.
• Результат з'являється в рядку кнопок під плеєром у тому ж стилі, що й лайк, дизлайк і «Поділитися». Світла й темна теми підтримуються.

Що важливо знати

• Розширення рахує лише те, що розпізнав YouTube. Автоматичні субтитри іноді пропускають швидкі «типу», тож справжня кількість, імовірно, трохи більша.
• Якщо у відео немає українських субтитрів, лічильник не показується.
• Поки обчислюється результат, розширення на кілька секунд може ввімкнути субтитри і потім повернути їх у попередній стан.

Конфіденційність

Розширення не збирає, не зберігає і нікуди не передає жодних даних. Усі обчислення відбуваються у вашому браузері, на сторінці відео. Немає аналітики, облікових записів чи зовнішніх серверів.

Розширення зроблено авторами подкасту «Радіо Кнопка» для розваги і не пов'язане з YouTube чи Google.

# Відповіді для розділу «Privacy practices» у дашборді

## Single purpose description

Counts how many times the Ukrainian filler word «типу» is spoken in a YouTube video, using the video's own captions, and displays the number next to the like and dislike buttons.

## Permission justification: host permission `https://www.youtube.com/*`

The extension runs only on YouTube watch pages. It needs access to youtube.com to read the caption data the YouTube player already loads for the current video, count the target word in it, and insert the counter element into the page next to the like/dislike buttons. No other sites are accessed.

## Are you using remote code?

No. All code is packaged in the extension.
