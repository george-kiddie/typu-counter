# Типу лічильник

Chrome-розширення, яке рахує, скільки разів у YouTube-відео прозвучало слово «типу»
(та варіації: тіпа, типа, типе), і показує це поруч із лайком/дизлайком.

## Встановлення

1. Відкрийте `chrome://extensions/`
2. Увімкніть «Developer mode» (верхній правий кут)
3. Натисніть «Load unpacked»
4. Виберіть цю папку (`Typu Extention`)
5. Відкрийте будь-яке YouTube-відео з субтитрами (зокрема автоматичними)

## Як це працює

YouTube віддає субтитри лише за запитом, підписаним токеном `pot`, який генерує сам плеєр.
Тому розширення не завантажує субтитри самостійно, а перехоплює відповідь плеєра:

1. `inject.js` запускається в головному світі сторінки до YouTube і патчить `XMLHttpRequest`/`fetch`,
   щоб перехопити відповідь `/api/timedtext`.
2. `content.js` просить `inject.js` обрати **український** трек через API плеєра
   (`#movie_player.setOption('captions', 'track', …)`). Це важливо для автодубльованих випусків,
   де є ще англійський трек і плеєр може обрати його за замовчуванням. Плеєр робить запит,
   `inject.js` його перехоплює, а потім повертає субтитри в попередній стан: вимикає їх,
   якщо були вимкнені, або повертає попередню мову.
3. Якщо API плеєра недоступне, є запасний шлях через кнопку CC.
4. Відповіді іншими мовами та автопереклад (`tlang`) ігноруються.
5. Результат кешується на відео, тож при поверненні на нього лічильник з'являється миттєво.

Мову можна змінити константою `TARGET_LANGS` у `content.js`.

Працює з SPA-навігацією YouTube (подія `yt-navigate-finish`).

## Структура

```
Typu Extention/
├── manifest.json   # MV3, два content scripts (MAIN + isolated world)
├── inject.js       # Перехоплення timedtext у головному світі сторінки
├── content.js      # Підрахунок і UI
├── styles.css      # Стиль «пігулки» YouTube, світла і темна тема
└── images/icon.svg
```

## Відомі обмеження

- Рахує тільки те, що розпізнав YouTube. Автоматичне розпізнавання української може
  пропускати або спотворювати «типу».
- Якщо у відео немає субтитрів, лічильник не показується.
- Якщо YouTube змінить структуру сторінки, селектори `#top-level-buttons-computed`
  і `.ytp-subtitles-button` можуть потребувати оновлення.
